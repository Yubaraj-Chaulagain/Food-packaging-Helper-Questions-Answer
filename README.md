# Interview Helper – Food Packaging (Offline Android APK)

GitHub-ready Android project for the Interview HTML app.

## Features
- Works offline using the bundled HTML in `app/src/main/assets/index.html`
- Portrait Android app
- App launcher icon uses the provided Interview Helper / Food Packaging portrait icon
- No internet permission is required for the offline app shell

## Build on GitHub
1. Upload this folder to a GitHub repository.
2. Open **Actions**.
3. Run **Build APK**.
4. Download the generated `Interview-Offline-APK` artifact.
